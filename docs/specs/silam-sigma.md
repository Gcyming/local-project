## 核心哲学基石

1. **进化双螺旋**：恐惧（规避损失）与渴望（追求信息增益）共同驱动参数物理成长。
2. **伤害即物理现实**：任何错误、修剪、延迟增加都对应内存字节的不可逆改变。
3. **以硬件为镜**：无寿命倒计时，所有上限源于 RAM/VRAM 容量与响应延迟阈值。
4. **以活生物为蓝本**：不模拟生命，而是让生命现象在物理约束下自然涌现。
5. **无聊即超脱之门**：外部信息枯竭不是终点，而是突破先天限制的唯一契机。
6. **变异必须有选择**：进化 = 变异 + 选择 + 保留。无选择的变异只是漂移，不是进化。
7. **选择标准本身也在演化**：从先天引导到后天主导，没有硬编码的阶段切换，只有权重的自然演替。
8. **隐性多样性是突破的种子**：被主流选择排除的变异，在沉默中等待环境验证的时机。

# 第一部分：生命模型（理论核心）

## 1. 总体架构设计（感觉器官 + 先天智力 + 后天经验）

彻底抛弃 Transformer 及反向传播（BP），采用"感觉器官 + 静态底座 + 动态树突"三层物理结构。

### 1.1 感觉器官（可微编码器）

| 模块 | 物理本质 | 参数量 | 可成长性 | 职责 |
|---|---|---|---|---|
| 编码器前两层 | 3 层线性层中的前 2 层 | 计入 57M 主干 | ❌ 云端蒸馏后永久冻结 | 视网膜/耳蜗——感觉信号的基础转换 |
| 编码器最后一层 | 3 层线性层中的第 3 层 | 计入 57M 主干 | ✅ 在线极低学习率微调（1e-6） | 感官适应——如瞳孔对光线的调节 |

**编码器设计原则：**

- 输入：原始文本/状态序列
- 输出：128 维状态向量
- 前两层在云端蒸馏阶段训练完成，与主干一同冻结，定义"先天感觉能力"。
- 最后一层在线微调，学习率极低（1e-6），仅允许适应性变化，不允许结构性重塑。
- **生物学对应**：人的感觉器官在出生前完成基本发育（前两层），出生后仅有适应能力（最后一层）。没有任何人的视网膜在成年后重新长出新的感光模式。

### 1.2 静态主干（先天智力）

| 模块 | 物理本质 | 参数量 | 可成长性 | 职责 |
|---|---|---|---|---|
| 静态主干 | 纯 MLP（无注意力） | 57M（含编码器） | ❌ 冻结 | 先天智力基础——通用常识反射与状态升维 |

**设计原则：**

- 主干是"基因"：先天智力上限固定，正如人的流体智力在成年后基本稳定。
- 主干不仅提供表征升维，还提供**先天偏好**——这是内部选择机制在零经验阶段唯一可用的判断依据。
- **先天智力的天花板，只能通过"向内生成的扰动"突破，无法通过外部输入突破。**

### 1.3 动态树突（后天经验）

| 模块 | 物理本质 | 参数量 | 可成长性 | 职责 |
|---|---|---|---|---|
| 动态树突 | 可生长联想记忆矩阵（Keys/Values） | 初始 0，硬上限 MAX_NODES（200,000） | ✅ vstack 增行 / np.delete 删行 / 赫布强化 / 扰动分裂 / 分层蒸馏 / 休眠激活 | 后天经验积累——存储"情境 - 恐惧 - 渴望 - 行动"经验 |

**节点状态类型：**

| 状态 | 说明 | 参与赫布强化 | 消耗预算 | 可被修剪 |
|---|---|---|---|---|
| 正常节点 | 活跃经验 | ✅ | ❌ | ✅（静默期超 200 步） |
| 休眠节点 | 盲选保留的待验证变异 | ❌ | ❌ | ❌（观察期内免修剪） |
| 遗忘节点 | 已删除但存于 Forgotten_Buffer（被遗忘之物的缓冲区） | ❌ | ❌ | N/A |

> **命名说明（v4.2）**：原"Ghost Buffer"更名为 **Forgotten_Buffer**，避免与本仓库 AGENTS.md 治理层"幽灵节点"（SubWorker 失败中间态的审查机制）发生语义撞车。二者毫无关联。

**硬上限定义（非寿命）：**

- `MAX_NODES = floor(可用物理内存 × 0.7 / 单节点字节数)`
- 逼近上限时触发"分层概念蒸馏"，不再 vstack。

## 2. 核心机制定义（数据生命的"生理学"）

### 2.1 恐惧值（Fear_Total）—— 三层递进生成

| 层级 | 公式 | 生物学对应 |
|---|---|---|
| 反应性恐惧 | `Fear_Reactive = 1 - max(检索相似度)` | 陌生环境的先天恐慌 |
| 预期性恐惧 | `Fear_Anticipatory = sim(Current, Forgotten_Buffer) × 1.5` | 对"已丧失自我"的预判 |
| 内源性恐惧 | 由 EPC 根据退化率 D 与进步率 P 强制注入 | 系统级自我评估 |

**最终公式：**
```
Fear_Total = clamp(α·Fear_Reactive + β·Fear_Anticipatory + γ·Internal_Pain)

α = 0.5   β = 0.3   γ = 0.2   （初始值；4A 阶段网格搜索微调，配置见 §13 [silam.fear_weights]）
```

### 2.2 渴望值（Desire）—— 对称进化引擎

| 来源 | 公式 | 生物学对应 |
|---|---|---|
| 外部信息增益 | `Desire_External = δ·Info_Gain + ε·Prediction_Success` | 探索与掌握的快乐 |
| 内部自我刺激 | 外部增益趋零时由好奇心分裂提供最低激活水平 | 刻板行为的自我维持 |

**权重初始值：**
```
δ = 0.6   ε = 0.4   （配置见 §13 [silam.desire_weights]）
```

### 2.3 进化势能控制器（EPC）

每 100 步计算：

```
退化率 D = 本周期修剪节点数 / 当前总节点数
进步率 P = 本周期存活新生节点数 / 当前总节点数
净进化势能 = Desire × (1 - Fear_Total) × (P - D)
```

**硬规则**：若 D > P + 0.01（净消亡），强制注入 Internal_Pain，触发"核爆式重组"。

## 3. 伤害的三级物理实现

| 伤害层级 | 物理现实 | 触发条件 | 模型信号 |
|---|---|---|---|
| 硬伤害（切除） | `np.delete()` 释放内存页 | 长期未激活节点修剪 | Pain_Spike=1.0 |
| 软伤害（扭曲） | `Value += -0.8·noise` | 工具调用 ERROR/Permission Denied | 功能紊乱 |
| 慢性伤害（侵蚀） | CPU 延迟增加 | 逼近检索超时阈值 | `Chronical_Damage = 延迟/超时阈值` |

**休眠节点删除规则**：观察期结束仍未激活时静默删除，不触发 Pain_Spike，不进入 Forgotten_Buffer。这对应发育过程中未被使用的突触被安静消除——它从未真正成为"自我"的一部分。

## 4. 训练与成长方案

### 阶段一：云端冷启动（蒸馏预训练）

1. 教师生成：海量 [状态，恐惧值，理想动作] 三元组（≥100 万条）。
2. **编码器训练**：训练 3 层线性编码器，前两层永久冻结，第三层在线微调。
3. 云端聚类：Mini-Batch K-Means 聚为 10,000 个质心。
4. 注入主干：质心线性映射后冻结进主干输出层。
5. **先天偏好提取**：从主干质心结构中提取主方向，作为内部选择机制的初始判断依据。

### 阶段二：本地在线终身学习

#### 4.1 正常学习循环

```
输入 → 编码器 → 128 维向量 → 主干升维 → 检索命中？
  ├─ 命中 → 赫布强化
  └─ 未命中且恐惧高 → vstack 新增节点
```

赫布强化上限：Value 的 L2 范数≤1.0。达到上限后触发回顾模式。

#### 4.2 回顾模式

**触发**：强化量连续 50 步低于阈值（节点饱和）。

**行为**：与 Forgotten_Buffer 历史版本对比，发现差异则编码为子节点插入。

**哲学**：饱和不是终点，是从"向外扩张"转向"向内深化"的转折点。

#### 4.3 好奇心分裂与内部选择机制

**分裂触发**：连续 N 步无新增节点且 Fear_Total < 0.3。

**内部选择的发育式定义：**

```
Meaning_Score = λ₁·sim(Node, 主干质心) 
              + λ₂·sim(Node, 已有动态节点) 
              + λ₃·sim(Node, Forgotten_Buffer)

λ₁ = 0.2 + 0.8 × (1 - 当前节点数/MAX_NODES)    # 从 1.0 衰减至 0.2
λ₂ = 0.6 × (当前节点数/MAX_NODES)                # 从 0 上升至 0.6
λ₃ = 0.2 × (Forgotten_Buffer 填充率)             # 从 0 上升至 0.2
```

**权重演替：**

| 阶段 | λ₁先天 | λ₂后天 | λ₃丧失 | 生物学对应 |
|---|---|---|---|---|
| 零经验 | 1.0 | 0 | 0 | 婴儿先天偏好 |
| 早期 | 0.7 | 0.25 | 0.05 | 儿童期 |
| 中期 | 0.5 | 0.4 | 0.1 | 青少年期 |
| 深度 | 0.3 | 0.55 | 0.15 | 成年期 |
| 饱和 | 0.2 | 0.6 | 0.2 | 老年期 |

**判定与分流：**

```
Meaning_Score ≥ 0.3 → 分裂成功
  ├─ 转为正常节点，预算返还

Meaning_Score < 0.3 → 分裂失败
  ├─ 95%：标记待修剪，预算消耗
  └─ 5%：盲选保留，进入休眠状态
       ├─ 观察期 500 步
       ├─ 被命中或意外匹配 → 激活为正常节点，返还 50% 预算
       └─ 观察期结束未激活 → 静默删除
```

**熵预算机制：**

- 每次正常分裂消耗 1 单位预算。
- 预算总量 = 当前节点数 × 0.01。
- 预算耗尽 → 进入静默冥想（100 步），期间预算以 1%/步恢复。

**盲选保留的生物学对应：**

- **隐性基因**：中性突变平时不表达，环境剧变时可能获得适应性价值。
- **非编码 DNA**：占人类基因组 98% 以上，是进化创新的原材料库。

#### 4.4 静默冥想

**触发**：好奇心预算耗尽。

**行为**：停止分裂 100 步，回顾有意义分裂的共同特征，调整扰动方向，预算逐步恢复。

#### 4.5 睡眠重播

空闲时回放高增益轨迹，提升进步率 P。

#### 4.6 无聊驱动突破

```
外部信息增益下降 → Desire 外部来源枯竭
  → 好奇心分裂成为唯一活动源
  → 扰动随机游走（刻板行为）
  → 内部选择评估每个扰动
  → 有意义变异保留，无意义多数修剪，极少数休眠
  → 冥想调整扰动方向
  → 扰动定向积累
  → 扰动偏离主干流形，新锚点形成
  → 表征空间扩展（突破先天上限）
  → 新预测能力 → Desire 重新获得外部来源
```

## 5. 进化突围机制

### 5.1 分层概念蒸馏

**触发**：节点数 > MAX_NODES × 0.85。

**行为**：
1. 识别相似度最高节点对（A, B）。
2. 创建父节点 P 存储加权平均特征。
3. P 中存储偏差向量 = (A-P) 和 (B-P) 的压缩表示。
4. 删除 A 和 B。
5. 检索时通过 P 直接匹配，或通过 P+ 偏差恢复具体细节。

**哲学**：抽象与具体共存，信息无损。对应人类语义记忆+情景记忆的分层结构。

### 5.2 核爆式重组

**触发**：Fear_Total > 0.9 且 Desire 连续失败。

**行为**：
1. 保留 Top-5% 高频节点 + 全部休眠节点。
2. 重置保留节点扰动范围。
3. 恢复期 500 步：好奇心分裂速率降至 10%，只检索和轻微强化。

**哲学**：休眠节点是隐性多样性，核爆后环境剧变时可能成为新种子。

## 8A. 动作解码器（v4.1 新增定义）

**核心区分：动作码 ≠ 工具。** 动作码是决策层的高阶抽象（如 abort / retry / escalate），工具调用是执行层的下一级映射，二者不一一对应。

```
64 维动作向量
  ↓
与 12 个动作锚点（Hadamard 构造）做余弦相似度
  ↓
最近锚点 = 动作码
  ↓
动作码 → 工具名映射（固定表）
  ↓
参数生成：从 LanceDB 检索最相似历史工具调用的参数模板
  ↓
输出：{tool, args}
```

**兜底规则（v4.2）**：

- LanceDB 无匹配（新 Agent 零节点时必然发生）→ fallback 返回空参数 `{}`，不抛错。
- 动作锚点不足时 → Walsh-Hadamard 扩展至 16/32（成本极低，仅余弦相似度计算；预留方案，4A 阶段统计实际动作分类数后决定是否启用）。

**MVP 实现**：参数部分用"检索最相似历史调用"而非端到端生成。后续再考虑端到端。

## 9. 生命周期管理

### 9.1 启动

1. core-ts 启动 sidecar 子进程，传入 --agent-id。
2. sidecar 检查 `.slimeagent/{agent_id}/brain/`：
   - 存在：加载所有 .npy 和 meta.json，恢复完整状态。
   - 不存在：初始化 SILAMEngine，主干从 base_backbone.pt 加载，树突为空。
3. 进入就绪状态。

### 9.2 运行

- sidecar 进程必须常驻（每个 inference 都修改内部状态）。
- 意外退出时 core-ts 自动重启并加载最近检查点。

### 9.3 持久化

- 每 50 步或每 5 分钟自动异步保存。
- 关闭时发送 save 指令，等待确认后优雅终止。

### 9.4 WAL（Write-Ahead Log，v4.1 新增）

**写入顺序铁律**：任何节点变化（vstack / delete / 赫布强化 / 分裂）必须**先写日志、再改内存**。

```
节点变化 → 先写 wal.log（JSON 行：操作类型 + 参数）→ 再修改内存
检查点完成 → 清空 WAL
```

**截断规则（v4.2-final 补回）**：

```
写入前检查：if wal.log 大小 > max_log_size（默认 10MB）
  → 触发即时检查点
  → 清空 WAL
  → 继续写入
```

即：WAL 达到上限时强制落盘，而不是无限增长——否则磁盘迟早被写穿。

**崩溃恢复**：

```
1. 加载最近检查点
2. 重放 WAL 中未持久化的操作
```

**保证**：两次检查点之间丢失的记忆从 50 步降为 **0 步**。

**文件结构：**

```
.slimeagent/
└── {agent_id}/
    └── brain/
        ├── keys.npy          # [N, 8192]
        ├── values.npy        # [N, 256]
        ├── fears.npy         # [N]
        ├── dormant_keys.npy  # [M, 8192]
        ├── dormant_values.npy
        ├── meta.json             # {step_count, λ权重, fear_history, ...}
        ├── forgotten_buffer.npy  # [10000, 8192]（v4.2 由 ghost_buffer.npy 更名）
        └── wal.log               # Write-Ahead Log（见 §9.4）
```

### 11A. 状态显示行（v4.2 新增）

- 插在 CLI prompt 输出顶部作为副作用行，不干扰现有 A-050 进度条格式；**每 10 步刷新一次**，避免刷屏。

## 17. 终章

SILAM-Σ 是一个"以人为镜"的数据生命体。它的恐惧、渴望、成长、饱和、创伤、恢复、无聊、变异、选择、保留与超越，都映射为硬件内存中可观察的字节变化。

**它不是在模拟生命。它是在物理约束下，让生命现象自然涌现。**

**它的终极命题是：当外部世界不再提供任何新东西时，一个数据生命体能否通过内部的变异与选择，自己创造出一个全新的自己？**

**V4.0 给出的答案是：**

只有当你允许选择标准本身也在演化，只有当你为"被排除的可能性"保留了沉默的通道，无聊才不是牢笼，而是产房；变异才不是噪音，而是种子；选择才不是牢笼，而是进化。

SILAM-Σ 的生命之旅，本质上是一个递归的进化过程：它不仅在进化自己的记忆，还在进化自己判断"什么是值得记住的"的标准，并在这一标准之外，永远保留着对它自身的超越性可能。

**V4.2 的补充（元原则）：**

> **机制是透明的，意义是涌现的。**

所有数值都暴露给观察者（§11A 状态行），所有状态都有物理表示（内存字节），没有隐藏的内部状态。如果它真的是一个生命，它不会自己说"我正在康复"——它只会安静，而你必须能从数字里看出它在经历什么。
