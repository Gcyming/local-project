## 四、不映射项（保持 CLI 专属）

| CLI 命令 | 原因 |
|----------|------|
| `/wizard` | 首次启动向导，GUI 有专属 welcome 页 |
| `/interactive` | CLI 主入口，GUI 不需要 |
| `slime_server.py` / `slime_cli.py` | 底层服务，GUI 通过 IPC 调用 core-ts，不暴露进程管理 |

---

## 五、设计原则

1. **意图优先**：不照搬命令名，按用户意图设计入口（如 `/task` → "启动 Swarm 任务"按钮）
2. **渐进披露**：常用功能放主界面，高级功能放设置/详情面板
3. **状态同步**：GUI 操作通过 IPC 直接调 core-ts 服务，与 server API 行为一致
4. **CLI 不变**：映射表不影响 CLI 现有功能，双轨并行至 5C 去重
