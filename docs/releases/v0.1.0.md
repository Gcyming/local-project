## 本版重点

**slime 长出了插件骨架，并且第一次把「自由度」交到插件手里 —— 外部插件可以说自己的话、摆自己的界面、占自己的一整块主区。同时本地 LLM 从"能起服务"变成"真能对话"。**

这一版是自 v0.0.9 之后的工作总汇（A-1197 ~ A-1201），主线有六条：

① **插件系统**：把「技能 / MCP / 工具」统一收进**插件**这一个容器，一次性补齐六类贡献点（设置 / 界面槽位 / 脚本信任 / 自有页面 / 阶段机 / 主题皮肤）；扩展页能按三类来源逐份展示与校验，并给出**拒绝原因**；官方示例扩展 `hello-slime` 同时是「活教材」与「一键安装」。

② **插件界面自由度**：界面槽位从 4 个固定位置扩到 **13 个区域**，插件可以贡献自己的 HTML 挂到任意区域；外观层支持**一个插件多套皮肤**与**自带图片资源**；插件还能开辟**自己的功能栏目** —— 其中「主区整块接管」意味着装上之后，整块对话区可以属于这个插件。

③ **撤除开发者模式**：把"高自由度"的实现从"内置开发者模式"改成"**可开可关的外部插件**"（武装 / 精装两条路），一次撤掉 15 个文件、523 行代码，并留下反回归锁。

④ **本地 LLM 真能用**：修掉三个各自独立的缺陷 —— 思考模式被硬编码强制打开（小模型因此只输出思考、正文为空）、模型名不许带小数点（照抄文件名会被拒收）、推理服务没有任何控制面（起没起、在哪儿、为什么失败全看不见）。

⑤ **git 工具层**：补上 commit 门禁、差异评审、无合并权三道闸，Agent 改代码不再是"想提交就提交"。

⑥ **工程**：TypeScript 存量错误清零、守卫与变异基建补齐两个批次、权限弹窗带差异评审、运行模式下拉。

## 一、插件系统：一切皆插件（A-1197 · A-1198）

**一句话**：插件是容器，技能与工具是它贡献出来的东西；插件的每一样能力都可以单独开、单独关，关掉即撤下。

**六类贡献点全部落地**：

- **设置**（`contributes.settings`）—— 插件自己的配置项直接长在扩展页里，密钥类字段只回传"有没有填"，不回传明文；
- **界面槽位**（`contributes.ui`）—— 插件把自己的按钮 / 状态项 / 工具入口挂到宿主界面上；
- **脚本信任**（`contributes.scripts`）—— 插件带的脚本默认**不信任**，用户显式打开开关才允许在本机以一次性子进程执行；
- **自有页面**（`contributes.page`）—— 插件可以给一整个页面，内容跑在隔离的沙箱框里；
- **阶段机**（`contributes.stages`）—— 会话可以按插件声明的阶段推进；
- **主题皮肤**（`contributes.theme` / `themes`）—— 见下节。

**扩展页重做**：三类来源（系统内置 / Agent 自建 / 外部载入）一屏看清；**校验不通过会逐条列出拒绝原因**（此前是静默忽略）；启停与信任改成「草稿 → 保存并生效」的**一个确定性生效点**——改完点右下角悬浮栏，主进程一次写盘 + 重扫 + 广播，**窗口不中断、进程不退出**。

**官方示例扩展 `hello-slime`**：既是能一键安装的示例，也是"贡献点该怎么写"的活教材。它把六类贡献点各演示一遍，装上就能在界面上看到效果。

## 二、插件界面自由度：从「插入点」到「整块栏目」（A-1200）

**一句话**：此前插件只能"在别人界面里加个小东西"，现在它可以**有自己的功能区**。

**13 个区域**：原来的 4 个固定槽位（设置面板 / 状态项 / 对话动作 / 工具栏）保留原名不变，另外新增标题栏两端、输入框前后、消息动作、侧栏、状态栏、以及两层浮层 —— **老插件零改动**。

**两种形态**：`item`（宿主渲染的按钮 / 一行）与 `panel`（插件自己的 HTML，宿主挂进沙箱框）。浮层区域专门接收 `panel`——宿主给一块全屏但"点不到"的空地，插件在里面**自己定位**，想贴哪儿贴哪儿。因为插件跑在独立文档里，它的层级**永远盖不住**宿主的确认弹窗。

**外观三件套**：

- 一个插件可以声明**多套皮肤**（上限 16 套），外观页按套展示、单独选用；
- 皮肤可以引用**插件自带图片**（这是唯一放开的 url 形态，且会被宿主改写成受控地址；外联地址一律拒绝）；
- 新增**全屏皮肤层**——插件可以整体改变应用观感，但同样盖不住确认按钮。

**插件自有栏目**（本版最直观的一格），三个落点：

- **主区整块接管**：对话与插件视图之间切换，切过去**整块区域归插件**。插件停用会自动回落对话，不留空白幽灵视图；
- **右栏多标签**：一个插件可以贡献多个右栏页签（此前是"一个插件一页"）；
- **左栏栏目块**：工作区列表下方的独立可折叠栏目。

**边界**：栏目内容仍跑在沙箱框里（插件在自己文档里爱怎么画怎么画，碰不到宿主）；单个插件最多 8 个栏目；停用即连同入口一起消失。

## 三、撤除开发者模式：高自由度 = 可开可关的外部插件（A-1198 续）

原先"高自由度"的一条实现路径是内置的开发者模式 —— 本版把它整个撤掉（15 个文件、523 行），改成两条外部路径：**武装**（外部插件能做什么）与**精装**（外观层能改什么）。

撤除的同时把"决定"变成机制：留下反回归锁，防止开发者模式换个名字长回来。

## 四、本地 LLM：从"能起服务"到"真能对话"（A-1201）

**一句话**：此前本地模型"服务是绿的、模型不说话"。三个缺陷各自独立，本版一起修掉。

**修复 1 · 思考模式被硬编码强制打开**（决定性）

推理型模型（qwen3 / deepseek-r1 一类）的对话模板里有一个"思考开关"。旧实现**对所有本地模型无条件下发"打开"**，于是小参数模型先狂写思维链、把输出预算吃光 —— 模型**返回空正文**，界面上看起来就是"它不理我"。

实测对照（qwen3-1.7b，输出预算 64）：

| 思考 | 结果 |
| --- | --- |
| 开（旧行为） | 正文为空；中间态还会把**截断的思维链泄漏成正文**（拿到的是"接下来，我要考虑用户可能的身份。"——那不是回答） |
| 关（新默认） | 正常回答 |

新行为给每个本地模型一个**思考模式**开关：自动 / 开 / 关。**"自动"的目标是保证有正文** —— 推理型模型自动帮你关掉思考，其余模型不下发这个参数。判据一句话：**能出正文，优先于能出思维链。**

**修复 2 · 模型名不许带小数点**

校验规则是从 API 供应商那边复用的（不含小数点），而模型文件的天然名字带小数点 —— 于是 `qwen3-1.7b` 这种照抄文件名的写法会被**拒收**，只有去掉小数点才能通过。本版给本地模型放宽一档（API 供应商那边保持严格，因为它们的名字参与寻址解析）。

**修复 3 · 补齐推理服务的控制面**

此前只有"模型增删查"，服务本身**看不见也管不动**。本版补齐：

- **状态**：角色 / 端口 / 进程号 / 显存占用 / 失败原因；
- **启停**：一键启动；「停止并释放显存」（下次对话会自动重新拉起）；
- **日志**：直接读推理服务的最近输出——启动失败、显存不足的第一手证据；
- **自检**：**真发一次请求**并如实回报耗时与回答样本；**空正文会被点名**并提示下一步怎么改。

自检用的参数与真实对话**完全同源**，不会出现"自检通过但真聊不出话"。

**本地模型配置页重做**：去掉让人猜的 K 单位（改为直接的 token 数并附一句人话）、去掉"GPU 层数 99"这种魔法数字（改成「全部层放显卡」的勾选）、每一项都补了一句说明、并把思考模式放到显眼位置。

## 五、git 工具层：三道闸（A-1198 续）

Agent 改代码不再是"想提交就提交"：

- **commit 门禁** —— 提交前必须过质量门；
- **差异评审** —— 权限弹窗里直接展示将要发生的改动，用户看着 diff 决定放不放行；
- **无合并权** —— Agent 不能自行合并分支。

## 六、工程与打磨

- **TypeScript 存量错误清零**（此前有历史欠账）；
- **守卫与变异基建**补两个批次，并修了两条基建级缺陷（夹具腐坏、子串假命中）；
- **四类界面槽位**的宿主接线、**运行模式下拉**（Agent / 计划 / 问答）落进界面；
- 写入守卫收敛到**单一产地**（跨插件写的边界收紧）。

---

## 已知限制（如实）

- 插件栏目的**切换状态不跨重启**保留（重开需重新点入口）；
- 单个插件的皮肤上限 16 套、栏目上限 8 个；
- `panel` 形态的界面块跑在沙箱框里，**不能复用宿主主题变量**（这是隔离的代价，插件需自带样式）；
- 本地模型的「单次最多输出」参数目前**留空即可**（引擎尚未消费该值）；
- 本版未更换打包内的推理引擎二进制（现有版本实测可用）。

---

## 升级提示

本版**无需卸载旧版**：安装包会原地升级，插件目录与设置保留。

如果你此前装过官方示例扩展，它会在**首次启动时自动升级到新版**（旧版会自动备份到 `config/plugins-backup/`，你的设置与信任状态都保留）。扩展页会如实告诉你升了什么。
