## 本版重点

**Office 文档从"能不能看"变成"保真地看"、搜索有了自己的索引与引擎、系统长出插件骨架与创造模式，右侧栏与动画在第一线被打磨了一个星期。**

这一版是自 v0.0.8 之后、连续十一天的工作总汇（A-1126 ~ A-1196），主线有六条：

① **Office 文档**：拖入即预览、右栏文档查看器、**新格式内置渲染 + 老格式 LibreOffice 转 PDF + 兜底路线**三层结构全部落地；
连每一类文件的"保真边界"都写进了产品（哪些格式原样、哪些结构化重排、哪些要装什么）。

② **搜索**：接入自建搜索（含网关薄代理）、分词与正文参数可调、模糊匹配、本地命中不足时自动联网补量；
连同"搜索页页头 logo 发糊"这种一眼可见的小毛病一起清掉。

③ **插件系统与创造模式**：技能 / MCP / 插件的关系被重新定义为"**一切皆插件**"——插件是容器、
技能与工具是贡献；扩展页可看到三类来源与逐份校验的拒绝原因；**创造模式下 Agent 可以为自己造插件**，
并且**知道自己能做什么、不能做什么**（能力自述）；深度用户还可以用 `loop_config` 定制 Agent 的循环预算。

④ **模型层与身份**：上游限流做成四层取值（手填 / 模型 / 供应商 / 全局）、对外请求统一诚实身份
（`slime/<版本>`，杜绝"同一个产品自称三个名字"）、**终止按钮在五处盲区上被彻底修通**
（点停止 1 秒内生效，最坏也有看门狗兜底）。

⑤ **右侧栏与窗口化**：右栏与对话页的窗口化解耦、一帧一帧的抖动被逐个消灭
（含"IACVT 帧""黑屏一帧""尾帧露字"这些只有实拍才能抓到的形态）。

⑥ **稳定性与工程**：SwarmExecutor 退役与遗骸清除、docs 全量整理归档、
变异基建补上两条铁律级教训（夹具腐坏、子串假命中），**全量测试第一次回到零红**。

## 一、Office 文档：从"拖进去"到"保真地看"（A-1133 ~ A-1136）

### 1. 拖入即预览

把工作文档拖进窗口即可在右侧栏打开；PDF、docx、xlsx、pptx、md、html 各有对应渲染器。
落地过程中修掉的问题包括：拖入触发的导航死循环、附件卡片不可点击、文件树无法收起、
以及"说了转 HTML 就要真的转 HTML 并当网页打开"。

### 2. 保真渲染的三层结构（A-1136）

用户口径是"**要像图片一样**"。最终形态：

| 层 | 覆盖 | 实现 |
| --- | --- | --- |
| 内置渲染 | docx / xlsx / pptx / pdf / html / 文本 | docx-preview、SheetJS、pptx-preview（随包分发，无需任何安装） |
| 老格式原样预览 | .doc / .ppt（97-2003） | LibreOffice 无头转 PDF 后内嵌查看（可选依赖） |
| 老格式兜底 | .xls | 没装 LibreOffice 时用 SheetJS 结构化重排，并在页顶**明示**"当前按表格方式显示，不是原版式" |

补充细节：老格式的**文本提取是纯内置**（OLE 二进制解析），Agent 读 .doc/.xls/.ppt 内容**不依赖 LibreOffice**；
Windows 上必须用 `soffice.com`（控制台版）而不是 `soffice.exe`（GUI 子系统会挂死），这条已是回归守卫。

### 3. 原生样貌（docView 渲染层）

文档查看器按 Office 原生观感排版：首行缩进、表格竖排单字修复、"连正常换行都不会"的 .doc 正则矛盾修复，
逐张截图打回、逐个真文件取证。

## 四、插件系统与创造模式（A-1191 ~ A-1196）

### 1. 一切皆插件

技能、MCP、系统内置能力的关系被重新定义为：**插件是容器，指令（技能）与工具是贡献**。
系统默认插件（builtin）由代码提供、不可卸载；Agent 自建与外部载入的插件逐份 fail-closed 校验
（清单字段、名字与目录一致、不可见 Unicode、origin 冒充 builtin 都会被拒绝，且拒绝原因逐条可见）。

### 2. 扩展页与拨片开关

三类来源（系统默认 / Agent 自建 / 外部载入）一目了然；**可管理插件的启停是一个拨片开关**：
关闭会写入禁用名单（`config/plugins-disabled.json`），**重扫与重启后都保持关闭**——不是一个只改当场状态的假开关。

### 3. 创造模式（面向深度用户）

- Agent 被授权后可以**为自己创建完整插件**（plugin.json + SKILL.md），并被要求**四步自验**
  （装载确认、可检索、实跑、失败即删）。
- **能力自述**：所有模式的 Agent 都知道"slime 通过技能 / MCP / 插件三层扩展能力、我当前处于什么模式、
  想扩展该找用户开什么开关"——不再出现"被问能不能给自己写插件、却只能列四个方向猜"的场面。
- **Loop 自由度（第一步）**：`config/agents.json` 里可为每个 Agent 配 `loop_config`
  （工具轮上限、工具调用次数、token 预算、墙钟上限；非法值回退默认、超限封顶）。
  完整的分层设计（含尚未实现的内核级自由度与先决问题）见 `docs/creator-freedom-design.md`。

## 五、模型层与身份（A-1129 ~ A-1132 · A-1192 · A-1194）

### 1. 空消息与正文口径

"聊久了就报 400"的真因是历史里一条空 user 记录（从 0.0.1 卡到 0.0.8）；
"正文非常长 / 疑似混进思考历程"的真因是两条工具循环收尾口径不一致——两处都修在根因上。

### 2. 上游限流与诚实身份

- 限流从"死开关"变成**四层取值**（手填 / 模型 / 供应商 / 全局），并有探针实测档位。
- 对外请求统一身份：`slime/<版本>`——此前同一产品在模型侧、GitHub 侧、下载侧自称三个名字，
  现在收归一处；供应商探测请求也补上同一身份。

### 3. 终止按钮响应性（A-1194）

用户报"终止按钮加载半天没反应、模型出问题停不下来"。查出**五处 abort 盲区**：
重试退避的 sleep 不打断、chromium 降级链把 abort 当普通失败继续重试、限流冷却期干等、
传唤与强制轮整条链没有 signal、工具批处理干等。全部修通，外加 UI 侧 15 秒看门狗兜底。

## 六、右栏 × 窗口化：交互地狱与"一帧"级修复（A-1142 · A-1153 ~ A-1190）

### 1. 会话隔离与右栏（A-1142）

右栏视图不再串台（切会话时工具面板内容严格跟随会话）。

### 2. 窗口化的交互地狱（A-1153 ~ A-1155）

右栏折叠/展开与对话页窗口化同时发生时会出现五类现象，最终定位到**四个独立根因**；
用真 App 端到端取证（CDP 探针）替代"读代码猜"，并对变异污染基线的事故做了完整复盘。

### 3. 动画与手感（A-1172 ~ A-1190）

一帧一帧地消灭：浮层态折叠留白、右栏窗口化抽搐、文本闪出、IACVT 帧、进入窗口化的一帧黑屏、
一帧可见抖动（用可见性判据 + 双采样抓到）、淡出触发源改绑盒子宽度（不是窗口 resize）、
以及两半动画的**同拍**（rAF duration 与 CSS transition 严格对齐；中间对话页的"凹陷"与侧边栏同步到 471/539 毫秒级）。
两次失败的尝试（A-1181/A-1182、A-1185/A-1186）被**完整回退**并留下成文教训——不推翻用实拍换来的决策。

## 已知边界

- 老格式（.doc / .ppt）的**原样预览**需要本机安装 LibreOffice（免费，约 350MB，不随包分发）；
  未安装时 .xls 会自动降级为结构化表格视图（页面顶部有明示），Agent 读取这些文件内容则无需任何安装。
- 表格类文件的**配色还原**受 SheetJS 社区版能力限制（不读单元格样式），兜底视图为结构化重排而非原版式。
- Excel 老格式（.xls）的兜底视图不保证公式计算后的数值展示，以文件内实际存储值为准。
