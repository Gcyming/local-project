## 体积分层：安装包瘦身 43%

上一版安装包 **978 MB**，其中 llama.cpp 的 CUDA 三件套（`ggml-cuda.dll` 513 MB + `cublasLt64_12.dll` 452 MB + `cublas64_12.dll` 95 MB）合计 1061 MB，占整个 payload 的一半以上——而纯 CPU 推理根本用不到它们。

本版改为**分层分发**：

| 产物 | 体积 | 说明 |
| --- | --- | --- |
| `Slime Setup 0.0.2.exe` | **560 MB** | 安装版（推荐），CPU 推理开箱即用 |
| `Slime 0.0.2.exe` | **559 MB** | 便携版，免安装直接运行 |
| `Slime-CUDA-Runtime-0.0.2.7z` | **308 MB** | 可选：仅 NVIDIA GPU 用户需要 |

压缩侧：随包资源先在打包前做 LZMA2 极限压缩（增补包 1061 MB → 308 MB，压缩率 71%），再进安装器；使用方下载后解压即可用。

### 需要 GPU 的话

1. 正常安装 Slime，安装完先退出。
2. 下载 `Slime-CUDA-Runtime-0.0.2.7z`。
3. 把压缩包里的 `llama.cpp` 整个目录解压到 Slime 的安装目录（默认 `%LOCALAPPDATA%\Programs\Slime`），同名文件选择覆盖。
4. 重新启动 Slime，本地模型即可走 GPU。

不需要 GPU 就不用下载它。缺少这几个 DLL 时 `llama-server` 会自动回落到 CPU 推理，不会报错。

## 修复与改进

- **差异详情不再静默截断**：原先超过 20000 字符的 diff 会被无声丢弃，界面上只剩一片空白的对比区。现改为渲染上限 400000、持久化上限 120000，并在确实降级时明确提示「改动过大，未内联展示前后对比」/「详情未保存」。
- **右栏在“非 git 工作区”不再显示裸报错**：过去会直接把 `fatal: not a git repository` 抛到界面上。现在先探测仓库状态，给出中文引导（黄色信息态，而不是红色错误）。
- **安装包不再携带调试残留**：界面探针截图目录（`layout-probe` / `browser-error-probe` / `_zoom` 等）和未使用的 llama.cpp CLI 工具（bench / imatrix / perplexity / quantize …）已从包内剔除。
- **构建侧**：清掉了源码树里 95 个被忽略的编译产物影子文件。它们会让测试守卫长期假绿（测的是冻结的旧副本，而不是源码）。

## 已知限制

- 便携版每次启动仍需把内容解压到临时目录，这是 electron-builder portable target 的固有机制，首次启动会偏慢。
- 安装包不含大模型 GGUF 文件，本地模型需自备或由内置下载器获取。
- 本次为 CPU 版运行时；GPU 用户请按上述步骤叠加 CUDA 增补包。
