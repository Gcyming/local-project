## 本版重点修复

**旧版 `.xls` 解析补全 —— 真实样本验证 + 数值不再丢**

上一版把 `.xls` 标为「已实现但未验证」。这轮取 Apache POI 的公开测试数据（5 个真实 `.xls`，
含日文作业表与 VBA 工作簿）跑了一遍，**验证暴露了一个真缺口**：

- 原实现只抽共享字符串表（SST），**纯数字单元格完全拿不到** ——
  `NUMBER` / `RK` / `MULRK` / `FORMULA`(数值) 四类记录都没解。
  一张以数字为主的表，读出来几乎是空的（`Formatting.xls` 只出格式名，数字 `10.52` / `39045` 全丢）。

### 修法：重建单元格网格

- 一遍扫描收全部记录 + `BOUNDSHEET`（表名 + `lbPlyPos`），按流偏移把记录归属到工作表
- 解 `LABELSST` / `LABEL` / `NUMBER` / `RK` / `MULRK` / `FORMULA`(数值缓存)，含 `RK` 的
  「位0=除100 / 位1=整数」两档编码
- 按表输出 `行号 + 列字母头 + 单元格`，空表如实标注（不假装有内容）
- 一个单元格都没解出来时**退回 SST 列表**（图表页等特殊结构仍能拿到文字）
