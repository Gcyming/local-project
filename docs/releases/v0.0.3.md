## 本版重点：旧版 Office 真解析 + 心智/记忆/知识三方闭环

### 新增能力

- **旧版 .doc / .xls / .ppt 真解析**（此前只报「暂不支持」）：自研 OLE2 复合文档读取
  （DIFAT / FAT / 目录项 / mini stream + miniFAT），`.doc` 走 piece table 还原正文、
  `.ppt` 取文本原子、`.xls` 取 BIFF8 共享字符串表。零外部依赖，只用 Node 内建模块。
- **心智 ↔ 记忆 ↔ 知识 三方闭环打通**：修掉四条「有实现、没接线」的断线 ——
  知识越阈值后自动生成技能（SKILL.md）并写入人格特征；知识里的高频项沉淀成行为模式；
  工具 / MCP 的调用成败回写成知识；自动生成的技能进入技能注册表，
  Agent 可用 `skill_search` / `skill_lookup` **真正调用**（此前这两个工具从未注册，技能形同虚设）。

### 修复

- **platform-tools 装不上**：解压不再依赖外部 tar / unzip（打包后进程 PATH 无 System32 时会 ENOENT），
  改用零依赖 ZIP 模块（含 Zip-Slip 防护）。
- **挂不上屏幕**：屏幕宿主改为按绝对路径启动（与上一条同一类根因）；
  修掉「单元素数组被折叠成标量」导致窗口枚举恒为空；窗口枚举返回形状异常时不再静默变成空列表。
- **读不了 PPT / Word / Excel**：`file_read` 支持 docx / pptx / xlsx，带轻结构
  （docx 段落+表格行、pptx 按页、xlsx 按表输出网格）。
- **改动对比展不开**：diff 标记此前只存在于当轮内存，重新打开会话即丢失；
  现在随思考记录一起落盘并在回看时还原。

### 体积

- 安装版 **559.9 MB** / 便携版 **559.5 MB**（上一版 978 MB，**−43%**）；
  CUDA 运行时单独成包 **307.9 MB**，只有 NVIDIA GPU 用户需要下载。

### 已知限制

- 旧版 `.doc` 若由**非标准写入器**（WPS / 第三方转换器）生成，其 fcMin 起的一段区域可能并非正文文本，
  解出来会是无意义汉字；已在返回信息中如实标注解析方式与建议。建议另存为 `.docx` 后重读。
- `.xls` 解析已实现，但**缺少真实样本验证**，目前仅覆盖合成路径。
