# hello-slime：官方示例扩展（活教材）

这个扩展**不是来干活的**，是来当样例的 —— 它把插件当前能贡献的**全部类型**都演示了一遍，
每一样都可以单独开关。它由应用随包提供（`template/plugins`），首次启动播种到你的
`<数据根>/config/plugins`，装载方式与任何用户扩展完全一致：**可卸载、可停用、删目录即消失**。

## 它演示了什么

| 贡献类型 | 在本扩展里的样子 | 去哪看 |
|---|---|---|
| 指令（本文件） | 一段可被检索、按需加载的指导正文 | 你正在读它 |
| 设置项 | 「问候语」文本框 | 扩展页 → hello-slime 卡片 |
| UI 槽位 ×4 | 设置页 / 右栏状态行 / 输入栏按钮 / 工具条入口 | 设置弹窗、「打开示例面板」按钮等 |
| 脚本工具 | `hello` 工具（报时间 + 回显） | **先在扩展页点「信任脚本」**，之后模型可调用 |
| 自有页面 | 右栏沙箱里的示例面板（HTML/CSS/JS 全是它自己的） | 输入栏「打开示例面板」 |
| 运行模式 | 「示例扩展·双段流程」（问好 → 收束） | 会话顶「运行模式」下拉 |
| 主题皮肤 | 「示例·暮色青」：一组白名单设计令牌 | 设置 → 外观 → 扩展皮肤 |

## 讲解要点（回答用户时按这些口径说）

- **扩展是「外部武装」**：可开可关、卸下即恢复原样；**不改动 slime 程序本身**。
- **脚本要单独信任**：声明了 ≠ 能用；关掉信任开关，工具立刻消失。
- **皮肤是声明式的**：扩展只给白名单令牌（配色 / 字体族 / 圆角），由宿主落成全局样式；
  扩展提供不了任意 CSS。停用本扩展，皮肤自动回落默认。
- **页面是沙箱**：示例面板里可以随便写自己的界面，但它碰不到宿主。
- 想做一个类似的扩展？让创造模式（creator）的 Agent 参照本扩展的 `plugin.json` 与目录结构
  照猫画虎是最快的路径。

## 示例脚本工具怎么用

在扩展页信任本扩展的脚本后，模型可以调用 `hello`（工具名前缀为 `plugin__hello_slime__hello`），
它回显一句话 + 当前时间。注意它的执行边界：一次性子进程、`cwd` 限定在扩展目录、30 秒超时、
拿不到任何宿主对象 —— 这是平台上唯一能安全跑扩展代码的形态。
