hello-slime · 示例面板

--:--:--
官方示例扩展的自有页面：HTML / CSS / JS 全部由扩展自己写 —— 这就是「完全自定义外观」的形态。

一、这块面板里，扩展能做主的部分

  • 任意布局、配色、字体、动效 —— 就像你现在看到的
  • 可以跑自己的 JS：右上角时钟每秒走动
  • 可以 fetch 同服务的资源（点下面的按钮试试读 plugin.json）

二、它碰不到的部分（结构性边界）

  • 宿主 DOM / 宿主样式表：沙箱 iframe 跨源隔离，摸不到
  • slime 的主题：想让整个应用换装，走 contributes.theme（本扩展就带了一套「示例·暮色青」）
  • 任意文件：页面只从 127.0.0.1 静态服务读本扩展目录内的文件

三、可开可关（「武装」口径）

关掉 hello-slime 的拨片：这块面板、输入栏按钮、状态行条目、示例皮肤、示例模式**全部消失**， 安静得像没来过；重新打开，它们原样回来。不修改 slime 程序本身，删掉并删除目录即彻底移除。 页面的关闭按钮在右栏标签上 —— 关掉后再点输入栏「打开示例面板」可再次打开。

页面地址由宿主按需起 127.0.0.1 静态服务提供（绝不用 file://）；本页不加载任何外部资源，离线可用。
